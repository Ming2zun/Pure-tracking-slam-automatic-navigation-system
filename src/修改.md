3. 
No transform from [front_left_steering_link] to [odom]
原因就是/joint_states没有给他发布数据，如果`ros2 topic echo /joint_states`运行后卡住了，说明就是这个问题，否则会有输出，比如
```
header:
  stamp:
    sec: 95
    nanosec: 738000000
  frame_id: ''
name:
- front_left_steering_joint
- front_right_steering_joint
- front_left_wheel_joint
- front_right_wheel_joint
- rear_left_wheel_joint
- rear_right_wheel_joint
position:
- 0.6001064798724487
- 0.6006190667872442
- 0.001096513025497181
- 0.0029116987090187507
- -0.007225084684206351
- 0.0005677904794918476
velocity:
- 0.02579023008984341
- -0.1136414803038674
- 0.006587464445457113
- 0.0066109828613626
- 0.004724979569069836
- 0.004710610050928537
effort: []
```
因此需要加上
```
<!-- 关节状态发布插件：发布 /joint_states 给 robot_state_publisher -->
<gazebo>
    <plugin name="joint_state_publisher" filename="libgazebo_ros_joint_state_publisher.so">
        <ros>
            <namespace>/</namespace>
            <remapping>~/out:=/joint_states</remapping>
        </ros>
        <update_rate>30</update_rate>
        <joint_name>front_left_steering_joint</joint_name>
        <joint_name>front_right_steering_joint</joint_name>
        <joint_name>front_left_wheel_joint</joint_name>
        <joint_name>front_right_wheel_joint</joint_name>
        <joint_name>rear_left_wheel_joint</joint_name>
        <joint_name>rear_right_wheel_joint</joint_name>
    </plugin>
</gazebo>
```
注意，这是Gazebo Classic（Gazebo 11）+ ROS2的写法，如果不是这两个，写法就会不同，如果gazebo sim的话，就需要使用gz_ros_bridge做桥接
